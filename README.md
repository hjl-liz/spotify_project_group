# Spotify User Analytics Project

## Overview

This project analyzes Spotify user listening behavior and evaluates the accuracy of Spotify's inferred audience segments. The goal is to identify patterns in user activity and compare them across multiple users.

## Team Members

* Colten Brandt

## Project Structure

* `data/` → User data and track metadata
* `notebooks/` → Analysis notebooks
* `src/` → Reusable Python functions
* `pyproject.toml` → Dependency management (Poetry)

## Setup Instructions

1. Clone the repository
2. Run `poetry install`
3. Open in VS Code
4. Select the Poetry environment
5. Run notebooks in order

## Technologies Used

* Python (Poetry)
* Pandas, NumPy
* Matplotlib, Seaborn
* Jupyter Notebooks

## Notes

* Data files are not included in this repository
* Use relative paths when working with data
